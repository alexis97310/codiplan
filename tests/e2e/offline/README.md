# Gardien hors-ligne — répertoire sanctuarisé

Invariant **I4** : toute fonctionnalité de l'application technicien est utilisable
en mode avion. Le scénario bout en bout — intervention complète hors réseau puis
synchronisation intégrale sans perte — est écrit aux tickets **L3-06 à L3-09**,
quand le socle PWA, le cache local et la file de synchronisation existent.

Ce répertoire est volontairement vide jusque-là. Il est exécuté par
`pnpm test:e2e`, donc par `pnpm verify:full`, porte de sortie de chaque lot.
